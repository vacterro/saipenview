VERIFIED REMAINING DEFECT

CORE-001 was closed too early.

The deterministic race tests in `tests/test_core001_mutation_scope.py` inject their barrier by wrapping `_revalidate_authorized()`.

The sequence exercised by the tests is therefore:

1. preview fingerprint authorization succeeds;
2. `_revalidate_authorized()` is entered;
3. test pauses before the real revalidation body;
4. external writer changes the path;
5. test resumes;
6. `_revalidate_authorized()` observes the new bytes and rejects them;
7. mutation is never attempted.

This does NOT test or eliminate the remaining race:

1. preview authorization succeeds;
2. `_revalidate_authorized()` succeeds;
3. external non-cooperating writer changes an authorized path;
4. `git add`, `git restore`, or `git clean` executes.

Application RootOwnership cannot serialize an external editor/process, so check-then-act revalidation alone is not an atomic authorization boundary.
