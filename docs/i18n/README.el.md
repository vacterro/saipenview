## 🧬 Πρωτόκολλο SAIPEN

Το SAIPENVIEW είναι συνοδός για έργα που χρησιμοποιούν το **Πρωτόκολλο SAIPEN** — ένα πλαίσιο μηχανής καταστάσεων που καθοδηγεί τους πράκτορες AI μέσω της εργασίας του έργου σε καθορισμένες φάσεις:

```
INIT → PLAN → SCOUT → BUILD → REVIEW → VERIFY → SHIP → DONE
                 ↓              ↓
            HUNT / CLEAN    VALIDATE
```

`ADD`, `MARKHUNT`, `TRANSLATE`, `PREPARE` υπάρχουν επίσης - το πλήρες λεξιλόγιο και ο πίνακας μεταβάσεων βρίσκονται στο `saipenview/protocol.py` (το `BLOCKED` είναι προσβάσιμο από τις περισσότερες φάσεις).
Κάθε έργο SAIPEN αποθηκεύει την κατάστασή του σε τρία κανονικά αρχεία:

| Αρχείο | Σκοπός |
|---|---|
| `.saipen/STATE.md` | Frontmatter αναγνώσιμο από μηχανή — φάση, εργασία, επόμενη ενέργεια, εμπόδιο |
| `.saipen/BOARD.md` | Πίνακας εισιτηρίων — ενότητες DOING / TODO / DONE / BLOCKED |
| `.saipen/LOG.md` | Χρονολογικό αρχείο καταγραφής συμβάντων — κάθε εντολή και το αποτέλεσμά της |

Οι **πράκτορες SubSaipen** (`saiwiki`, `saihunt`, `saitranslate`) βρίσκονται στο `.saipen/extensions/subs/` και επικοινωνούν μέσω του `kitchen/OUTBOX.md` — τον ενσωματωμένο δίαυλο μηνυμάτων μεταξύ πρακτόρων του πρωτοκόλλου. Το SAIPENVIEW ανακαλύπτει όλους αυτούς και αποδίδει έναν ενοποιημένο πίνακα ελέγχου.

### Συμμόρφωση

Η εμφάνιση του τι *λέει* ένα έργο είναι μόνο το μισό. Ένα έργο μπορεί να διαβάζεται τελείως
σωστά στη λίστα — μια φάση, μια εργασία, μια επόμενη ενέργεια — ενώ βρίσκεται σε μια κατάσταση που το πρωτόκολλο
απορρίπτει, και μέχρι να εκτελέσετε το `tools/validate.py` χειροκίνητα δεν υπήρχε τρόπος να ξεχωρίσετε
αυτά τα δύο.

Κάθε σειρά φέρει ένα σήμα ετυμηγορίας, και το πλαίσιο λεπτομερειών αναφέρει τι είναι λάθος:

| Ετυμηγορία | Σημασία |
|---|---|
| `OK` | Δεν βρέθηκε τίποτα στα αρχεία `.saipen/` αυτού του έργου |
| `N WARNS` | Νόμιμο, αλλά αποκλίνει — ένα παλιό σημείο ελέγχου, ένα μη τυπικό ρήμα LOG |
| `N FAILS` | Μια κατάσταση που το πρωτόκολλο απορρίπτει: ένα `WAIT:` χωρίς κατηγορία, ένα πλαίσιο ελέγχου που διαφωνεί με την ενότητά του, ένα `needs:` που δείχνει σε εισιτήριο που δεν υπάρχει, ένα UTF-16 `STATE.md` που κανένα άλλο εργαλείο SAIPEN δεν μπορεί να διαβάσει |

Κάθε εύρημα ονομάζει τον κανόνα, το αρχείο και τη γραμμή, καθώς και τηρήτρα από την οποία προέρχεται,
ώστε να μπορεί να αναζητηθεί αντί να γίνει αποδεκτό στα τυφλά.

Αυτή είναι μια **δεύτερη γνώμη, όχι αντικατάσταση** του `tools/validate.py`.
Επανελέγχει μόνο όσα μπορούν να αποφασίσουν τα ίδια τα αρχεία του έργου και βαθμολογεί έναντι ενός
αντιγράφου των λεξιλογίων του πρωτοκόλλου — έτσι η έκδοση SAIPEN από την οποία αναγνώστηκε
τυπώνεται κάτω από κάθε ετυμηγορία. Ο προβολέας επιτρέπεται να καθυστερεί σε σχέση με το πρωτόκολλο. Δεν
επιτρέπεται να καθυστερεί σιωπηλά.

> 💡 *Το όνομα "SAIPENVIEW" τα λέει όλα — παρέχει μια **προβολή (view)** σε κάθε έργο **SAIPEN** στον υπολογιστή σας.*

## ⚙️ Ρύθμιση

Η διαμόρφωση είναι φορητή — αποθηκεύεται δίπλα στην εφαρμογή, όχι στο `%APPDATA%`:

```
saipenview/_data/config.json
```

Κύριες προεπιλεγμένες τιμές (συντομευμένο - το πλήρες λεξικό `DEFAULTS` βρίσκεται στο `saipenview/config.py`):

```json
{
  "hotkeys":          ["ctrl+alt+x", "alt+f15"],
  "snap_hotkey":      ["alt+f14"],
  "zoom_level":       1.0,
  "font_family":      "Verdana_m1",
  "scan_roots":       null,
  "rescan_interval":  300,
  "scan_depth":       6,
  "scan_delay_ms":    10,
  "exclude_dirs":     [],
  "auto_scan":        true,
  "show_on_launch":   true,
  "always_on_top":    true,
  "frameless":        true,
  "flash_changes":    true,
  "locale":           "en",
  "default_engine":   "claude-code",
  "file_viewer_default": "source",
  "layout_swap":      false
}
```

Ορίστε το `scan_roots: null` για αυτόματο εντοπισμό όλων των τοπικών δίσκων.  
Ορίστε μια λίστα διαδρομών (π.χ. `["V:\\", "D:\\projects"]`) για περιορισμό της σάρωσης.  
Το `default_engine` / `engine_overrides` / `agent_output_buffer_size` οδηγούν το Agent Engine (δείτε Χαρακτηριστικά).  
Όλες οι ρυθμίσεις διαμορφώνονται επίσης μέσω του παραθύρου **Ρυθμίσεις** στην εφαρμογή.

### Αρχές σχεδιασμού

- **Μία διεργασία** — χωρίς IPC παρασκηνίου, χωρίς ξεχωριστό διακομιστή. μία διεργασία Python φιλοξενεί τόσο το παράθυρο WebView2 όσο και τον βρόχο σάρωσης σε ένα `ThreadPoolExecutor`
- **Ατομικές εγγραφές** — κάθε εγγραφή αρχείου χρησιμοποιεί προσωρινό αρχείο + `os.replace`. μια κατάρρευση δεν μπορεί ποτέ να αποκόψει τη διαμόρφωση ή την κρυφή μνήμη
- **Ασφαλής από παλιές αναγνώσεις** — η δημοσκόπηση UI 5s καλεί τη `refresh_known()` (επανανάγνωση μόνο αρχείων `.saipen/`, χωρίς σάρωση καταλόγων). Οι επεξεργασίες στο STATE.md εμφανίζονται σε δευτερόλεπτα χωρίς να πυροδοτείται πλήρης σάρωση δίσκου
- **Χωρίς μεταβάσεις CSS** — όλα τα οπτικά εφέ (αναλαμπή, θερμότητα, αιώρηση) είναι επανυπολογισμοί `hexBlend` μέσω JavaScript, ακολουθώντας αυστηρά τον περιορισμό μηδενικών κινούμενων σχεδίων του vintage θέματος
- **Vintage θέμα** — σκούρες καφέ επιφάνειες, χρυσό κείμενο/τονισμοί, τρισδιάστατα περίγραμμα με φάλτσο, μηδενική εξομάλυνση, γραμματοσειρά Verdana_m1

## 🧪 Ανάπτυξη

```bash
# Κλωνοποίηση & είσοδος
git clone https://github.com/vacterro/saipenview.git
cd saipenview

# Δημιουργία venv & εγκατάσταση
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# Εκτέλεση
python -m saipenview
```
