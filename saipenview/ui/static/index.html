SAIPENVIEW Help
Getting Started

SAIPENVIEW discovers every SAIPEN project on your machine and shows its live state — phase, task, git status, tickets, and sub-agents — all in one vintage-themed dashboard.

  • Launch — run.vbs (hidden, tray-only) or run.bat (console visible)
  • Toggle window — Ctrl+Alt+X or Alt+F15
  • Snap corner — Ctrl+Q cycles through TL / TR / BL / BR
  • Zoom — Ctrl+MouseWheel or Ctrl+/-/0
  • Kill switch — Ctrl+Shift+Alt+Q force-exits
Project List
  • Pin — ★/☆ to keep a project at the top
  • Hide — ✕ removes from list (restore via H checkbox)
  • Filter — Live / Done / Stuck via dropdown, or click a phase pill
  • Sort — Smart / Recent / Oldest / A–Z / Z–A
  • Search — type to filter by name or path; tick D for deep ticket search
  • Compact — C checkbox for condensed rows
  • Right-click — copy root path or filter by phase
Detail Pane
  • Actions — Folder / CMD / Code buttons open project in explorer, terminal, or VS Code
  • Quick actions — detected from project type (npm, cargo, make, etc.)
  • Edit state — click Edit to change Next Action and Task; auto-refresh pauses
  • SAIPEN files — STATE / BOARD / LOG buttons open files in the built-in viewer
  • Collapse sections — click any section header to collapse; state persists per project
  • Double-click — on any collapsible header opens the connected file
  • Sub-agents — S / B / L buttons open sub-agent files; OUTBOX shows findings
Scanning & Discovery
  • Auto-scans all local drives (except C:\) on startup
  • Browse — add a specific folder to the scan set
  • Rescan — force an immediate full re-scan
  • Projects cache to disk for instant cold-start display
  • Linked git worktrees (no .saipen/ dir) detected and shown separately
  • Scan errors appear as a red ! badge — click to view
What is SAIPEN?

SAIPEN (Self-Adaptive Iterative Protocol for Enhanced Navigation) is a state-machine protocol that guides AI agents through project work in phases: PLAN → SCOUT → BUILD → VERIFY → REVIEW → SHIP → DONE, plus HUNT (bug chasing) and CLEAN (debt reduction). Each project carries its state in .saipen/STATE.md.

SubSaipen Agents

SubSaipen are read-only research agents that work alongside the main agent:

  • saiwiki — documents the project (wiki pages, architecture, API refs)
  • saihunt — hunts for bugs: null safety, exceptions, race conditions, resource leaks
  • saitranslate — translates documentation into other languages
  • Each sub writes findings to its kitchen/OUTBOX.md for the main agent to collect
File Viewer
  • Source / Reader — toggle between raw markdown and a structured rendered view
  • STATE.md renders frontmatter fields, BOARD.md groups tickets by section, LOG.md parses event lines
  • Save — edits in Source mode can be saved back to the file
